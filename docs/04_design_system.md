# デザインシステム：Cybernetic Twilight（サイバー・トワイライト）

## 1. デザインコンセプト
**「ネオン・トワイライト × 機能美を纏った近未来サイバネティクス」**
インディゴ〜ネオンマゼンタの空と、バイオレット系ダークメタルの機械構造に、シアン／マゼンタ／ミントの発光を重ねることで、幻想的かつSF的な浮遊世界観を構築する。

## 3. ボクセル造形ルール（Voxel Modeling Guidelines）
1. **グリッド整合性**: すべての静的建築・地形パーツは整数座標グリッドにスナップさせ、ボクセル特有のシャープなシルエットを維持する。
2. **エッジの可視化（マイクロベベル／目地表現）**: ボクセルジオメトリは `0.985` スケールを持たせ、隣接する同色ブロック同士がのっぺりと一体化することを防ぐ。
3. **発光パーツの配置比率**:
   - 画面全体の **85% 以上** を低彩度・暗色系の岩盤・メタルで構成し、ネオン光の反射面とする。
   - 発光（Emissive）ボクセルは **5%〜10%** に抑えることで、ピンクの窓やシアンのコアが宝石のように際立つ視覚階層を作る。

## 4. HUD / UI コンポーネント仕様
3D キャンバスの視認性を妨げないよう、UI は画面四隅に最小限配置し、**ダーク・グラスモーフィズム** で統一する。

- **背景サーフェス**: `rgba(15, 23, 36, 0.65)` + `backdrop-filter: blur(10px)`
- **ボーダー**: `1px solid rgba(0, 240, 255, 0.28)`（シアンアクセントの極細枠線）
- **タイポグラフィ**:
  - 見出し・数値バッジ: `'Inter', 'Segoe UI', monospace`（等幅数字 `tabular-nums` を使用し、FPS やブロック数の数値ブレを防止）
  - 本文・日本語ラベル: `'Noto Sans JP', sans-serif`
- **インタラクティブ状態**:
  - 通常時: テキスト `#E2E8F0`
  - ホバー／アクティブ時: ボーダー `#00F0FF`、微弱な外光シャドウ `0 0 12px rgba(0, 240, 255, 0.35)`
