# 要件定義書：空に浮かぶサイバネティック水車小屋（ボクセルアート）

## 1. プロジェクト概要
### 1.1 目的
Three.js を用いた 3D ボクセルアート表現により、「夕暮れの空に浮かぶサイバネティックな水車小屋」をブラウザ上でリアルタイムに描画・鑑賞できる単一 HTML アプリケーションを構築する。

### 1.2 ターゲット環境
- デスクトップおよびモバイルのモダン Web ブラウザ（Chrome, Firefox, Safari, Edge 最新版）
- ビルドツールや外部ローカルアセットに依存せず、単一 HTML ファイル（`index.html`）のみで完結・動作すること。

## 2. 機能要件（Functional Requirements）

| ID | カテゴリ | 要件名 | 詳細仕様 |
| :--- | :--- | :--- | :--- |
| **FR-01** | 地形造形 | 浮遊島の生成 | 直径 80 ブロック（半径 40 ブロック）の円盤〜逆円錐状の浮遊島をボクセルで構築する。上面には水路と崖端の滝口を備え、下部には反重力コアとエネルギーリングを配置する。 |
| **FR-02** | 建築造形 | 水車小屋の生成 | 近未来・サイバネティック意匠の水車小屋を構築する。外壁はダークメタリック調とし、窓は黄色く発光させる。 |
| **FR-03** | 動的オブジェクト | 水車の回転 | 直径 14 ブロック（半径 7 ブロック）の水車を小屋側面の川沿いに配置し、約 **8.0 秒で 1 周**（360度）する等速円運動を行う。 |
| **FR-04** | 自然環境 | 植生の配置 | 浮遊島上に **5〜8 本**（標準 7 本）のサイバネティックな樹木を配置する。 |
| **FR-05** | パーティクル | 滝の表現 | **300 個** のボクセルパーティクルを用い、崖端から落下・拡散し続ける滝アニメーションを表現する。 |
| **FR-06** | カメラ制御 | 自動周回と手動操作 | カメラは浮遊島を中心に **40.0 秒で 1 周** する水平オービット回転を行う。ユーザーによるマウス／タッチ操作（回転・ズーム・パン）および自動回転の ON/OFF 切替に対応する。 |
| **FR-07** | 背景・照明 | 夕方の空とライティング | 天頂が濃い青、地平線がオレンジ色にグラデーションする夕暮れの空を描画し、時間帯に合わせた環境光・太陽光・ポイントライトを配置する。 |

## 3. 非機能要件（Non-Functional Requirements）

| ID | カテゴリ | 要件名 | 目標値・制約条件 |
| :--- | :--- | :--- | :--- |
| **NFR-01** | パフォーマンス | 総ブロック数上限 | シーン内の描画ボクセル総数を **100,000 個以内** に抑える（表面カリングにより 25,000〜40,000 個程度へ最適化）。 |
| **NFR-02** | パフォーマンス | フレームレート | 標準的な PC 環境において **60 FPS** での安定動作を目指す。 |
| **NFR-03** | 配布・ポータビリティ | 単一ファイル完結 | HTML / CSS / JavaScript / GLSL シェーダーを 1 つの `.html` ファイルに集約し、外部 3D モデルやテクスチャ画像ファイルを不要とする。 |
| **NFR-04** | レスポンシブ性 | 画面リサイズ追従 | ウィンドウサイズ変更時にアスペクト比とレンダリング解像度（`devicePixelRatio`）を即座に再計算する。 |

---

## 4. 受け入れ基準（Acceptance Criteria）
1. ブラウザで `index.html` を開いた際、エラーなく 3D シーンが初期表示されること。
2. 島の直径が 80 ブロック、水車の直径が 14 ブロック、木が 5〜8 本の範囲で構成されていること。
3. 水車が約 8 秒周期、カメラが約 40 秒周期で滑らかに回転すること。
4. 滝のパーティクルが 300 個描画され、途切れることなく循環落下すること。
5. 画面上部の空が濃い青、下部がオレンジ色の夕景であり、小屋の窓が黄色く発光していること。
6. `THREE.InstancedMesh` を使用し、総インスタンス数が 100,000 以下であることが統計情報・コード上で保証されていること。
