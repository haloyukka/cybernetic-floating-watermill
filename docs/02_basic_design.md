# 基本設計書：空に浮かぶサイバネティック水車小屋

## 1. システムアーキテクチャ
本アプリケーションは外部サーバー通信を行わないクライアントサイド完結型の WebGL アプリケーションである。

```text
+-------------------------------------------------------------------+
|                         index.html (Single File)                  |
|  +-----------------------------+  +----------------------------+  |
|  |       HTML / CSS HUD        |  |     Three.js Engine        |  |
|  | - タイトル / ステータス表示 |  | - WebGLRenderer (Shadows)  |  |
|  | - カメラ自動周回切替ボタン  |  | - PerspectiveCamera        |  |
|  | - 操作ガイド表示            |  | - OrbitControls            |  |
|  +--------------+--------------+  +-------------+--------------+  |
|                 |                               |                 |
|                 v                               v                 |
|  +-------------------------------------------------------------+  |
|  |                  Scene Builder & Voxel Engine               |  |
|  | 1. VoxelGrid (84 x 76 x 84) 生成 & 表面カリング             |  |
|  | 2. Material別 InstancedMesh バッチ生成 (<= 100,000 blocks) |  |
|  | 3. 動的パーツ生成 (水車 14φ / 滝 300粒 / コアリング)      |  |
|  | 4. Custom SkyDome Shader (夕暮れグラデーション)            |  |
|  +-------------------------------------------------------------+  |
+-------------------------------------------------------------------+
```

## 2. 空間座標系とワールドレイアウト設計
Three.js の右手座標系を採用し、**1 ボクセル = 1.0 ワールド単位** とする。

- **原点 `(0, 0, 0)`**: 浮遊島の最上面（地表基準レベル `Y = 0`）の中心点。
- **X 軸**: 東西方向（`-40` 〜 `+40`）。水路および滝の流出方向を `+X` 側とする。
- **Y 軸**: 高さ方向（島下部 `-46` 〜 水車小屋屋根頂部 `+24`）。
- **Z 軸**: 南北方向（`-40` 〜 `+40`）。

### 2.1 主要オブジェクト配置設計

| オブジェクト | 中心座標 `(X, Y, Z)` | 寸法（ブロック単位） | 備考 |
| :--- | :--- | :--- | :--- |
| **浮遊島本体** | `(0, 0, 0)` 基準 | 直径 `80` × 高さ約 `40` | 上面フラット＋段差、下部は逆円錐状岩盤 |
| **水路・川** | `X: -24 〜 +40, Z: 0` | 幅 `6` × 深さ `2` | `+X` 端（`X = +39`付近）から滝として落下 |
| **水車小屋** | `(-5, 0, -10)` 付近 | 幅 `14` × 奥行 `12` × 高さ `16` | 水路の北側（`-Z`側）に隣接配置 |
| **水車** | `(-3, 5, -2)` 付近 | 直径 `14` × 幅 `3` | 水路直上に配置し、X-Y 平面上で Z 軸回転 |
| **サイバーツリー** | 島内各地点（7箇所） | 高さ `9` 〜 `14` | 水路・小屋と干渉しない外周・丘陵部に配置 |
| **反重力コア・リング** | `(0, -42, 0)` 付近 | コア径 `5` / リング径 `20, 28` | 浮遊島最下部に浮遊・逆位相回転 |
| **滝パーティクル** | `X: +39.5, Y: -1 〜 -46` | 粒子サイズ `0.48` × `300個` | 崖端から重力加速度で落下・ループ |

## 3. レンダリング・パフォーマンス最適化方針
### 3.1 表面カリング（Hidden Surface Removal）
直径 80 ブロックの島を中実（ソリッド）で描画すると約 10 万〜15 万ブロックに達し、描画負荷増大およびブロック数上限に抵触する。そのため、以下の最適化を行う。
1. 静的ボクセル（島・岩盤・水路・水車小屋・樹木）はすべて 3 次元論理グリッドに一度格納する。
2. 各ボクセルの上下左右前後（6近傍）を検査し、**6方向すべてが不透明ボクセルで埋まっている内部ブロックは描画対象から除外** する。
3. 露出した表面ブロックのみを抽出し、マテリアル種別ごとに `THREE.InstancedMesh` へ一括転送する。

### 3.2 ドローコール削減
- 同一マテリアル（色・質感・発光属性）を持つボクセルは 1 つの `InstancedMesh` に統合する。
- これにより、数万個のボクセルをわずか **12〜16 ドローコール** で描画する。

## 4. ライティング・雰囲気設計
- **スカイドーム**: 半径 450 の球体メッシュにカスタム GLSL シェーダーを適用し、天頂（`#0B192C`）から地平線（`#FF6B35`）への夕焼けグラデーションと、天頂付近の微細な星空を描画する。
- **キーライト（DirectionalLight）**: 地平線に近い低角度（仰角約 18°）から暖色オレンジ光（`#FF9E5E`）を照射し、長い夕暮れの影を落とす。
- **環境光（HemisphereLight）**: 空側の青紫（`#3A5F8A`）と地面照り返しのオレンジ（`#D96B27`）を設定し、影面にも豊かな色調を与える。
- **ポイントライト（PointLight）**: 水車小屋内部（黄色窓の光源）と島下部の反重力コア（シアン光源）に配置し、周辺ボクセルを照らし出す。
